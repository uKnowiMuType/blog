# 通过路径平坦性提升对抗迁移性的方法综述

> 覆盖 [[2023_PGN]]、[[2024_TPA]]、[[ANDA_2024_deep_note]]、[[2025_GAA]]、[[2026_MEF]] 五篇论文，梳理"损失面平坦性 → 对抗迁移性"这条研究主线的理论演进与方法谱系。

## 一句话总览

这条线的全部工作都源自对模型泛化理论的一个类比：

$$\text{平坦局部极小值} \rightarrow \text{好泛化（已确立）} \;\Rightarrow\; \text{平坦局部极大值} \rightarrow \text{好迁移性（待验证）}$$

五篇论文构成一条完整的演进链：

> **假设**（PGN）→ **质疑与理论界**（TPA）→ **分岔**（GAA 显式曲率 / ANDA 分布视角）→ **统一理论与收口**（MEF）

| 论文 | 对平坦性的核心论断 | 优化的平坦性量 |
|---|---|---|
| PGN (NeurIPS 2023) | 首次实证建立"平坦→迁移"假设，惩罚邻域最大梯度范数 | 一阶 · 最坏情况：$\max_{x'\in B_\zeta}\|\nabla J(x')\|_2$ |
| TPA (NeurIPS 2024) | **推翻"平坦即充分"**：迁移上界 = 固有模型差异 + 一阶 + 二阶分量 | 一阶 · 平均情况（邻域期望梯度范数，隐式压二阶） |
| ANDA (CVPR 2024) | 旁支：估计扰动**后验分布**，用分布几何取代单点优化 | ——（SGA 渐近正态分布的前两阶矩） |
| GAA (TIFS 2025) | 平坦性要有**显式度量**：替代间隙 ∝ Hessian 最大特征值 | 零阶 · 最坏 + 隐式二阶曲率 |
| MEF (TIFS 2026) | 统一理论：ATG 上界由 n 阶平坦性 + 跨模型梯度差异决定，零阶主导；暴露过探索/过利用困境 | 零阶 · 最坏外 × 平均内（maximin 结构） |

---

## 一、PGN：有限差分把"惩罚梯度范数"变成梯度插值

**定位**：整条线的起点。首次把"平坦局部最优 → 高迁移性"从泛化理论类比升级为可验证假设（Assumption 1）并给出实证。

**核心目标**：

$$\max_{x^{adv} \in B_\epsilon(x)} \left[ J(x^{adv}, y) - \lambda \cdot \max_{x' \in B_\zeta(x^{adv})} \|\nabla_{x'}J(x', y)\|_2 \right]$$

两个有意识的设计选择：

1. **用 max 而非 avg 定义邻域平坦度**——平均梯度会被大量"平坦方向"稀释而漏掉少数尖锐方向，最大值对锋利程度更敏感。
2. **Hessian-向量积用有限差分近似**，最终更新梯度退化为优雅的**双点梯度插值**：

$$\nabla_{x^{adv}}\mathcal{L} \approx (1-\delta)\cdot g(x') + \delta \cdot g(x' + \alpha v)$$

即"当前邻域点梯度"与"沿归一化梯度方向 v 前进一步处梯度"的凸组合（δ=0.5 最优），天然感知梯度方向上的局部曲率；再以 N=20 次采样平均降方差。

**效率与结果**：相比直接算 Hessian 4.9× 加速、4.8× 省显存，ASR 仅降 1-2%；单模型平均 ASR 76.7-82.9%，集成 92.78%，对抗训练模型最高 79.2%，ViT 56.98%（比 RAP +12.5%）。

**局限**：平坦性→迁移性只是相关性证据，无因果证明；ζ、δ 手工调优。

## 二、TPA：理论证明"平坦性不充分"

**定位**：第一个对社区共识发难的严格理论工作。首次推导可迁移性的理论界（Theorem 3.1），证明**平坦性增加并不必然提升迁移性**。

**核心定理**：在五个实践假设（p(x) 有界、梯度有界、p(x+δ)≤p(x)、代理损失≥目标损失、ReLU 架构）下，将目标模型损失解耦为 $L(F'(x+\delta)) = L(F(x+\delta)) + D(x+\delta)$，迁移损失项的期望上界由三部分构成：

$$\mathbb{E}\{\|D\|^2\} \le \underbrace{\text{固有模型差异分量}}_{\text{预测对齐决定}} + \underbrace{(1{+}C)\,\mathbb{E}\{\|\delta\|^2\|\nabla\log F\|^2\}}_{\text{一阶梯度分量（平坦性）}} + \underbrace{2\,\mathbb{E}\{\|\delta\|^2\sum_i|\nabla^2\log F[i,i]|\}}_{\text{二阶梯度分量}}$$

**反例 $y=\sin(x^2)$**：x=0 处一阶梯度为零（最平坦），但二阶梯度最大——**单纯追平坦可能落到次优解**。平坦性只是三个决定因素之一。

**方法**：惩罚**邻域期望**梯度范数 $\mathbb{E}_{\Delta\sim U(-b,b)}\|\nabla L(x+\delta+\Delta)\|$ 而非点梯度（与 PGN/GNP 的本质区别）。原理：邻域梯度→0 时，一阶分量与二阶分量**同时**→0。Hessian 项同样用梯度差分技巧化解：

$$Hv \approx \frac{\nabla L(x+kv) - \nabla L(x)}{k},\quad v = \frac{\nabla L}{\|\nabla L\|_2}$$

**副产品洞察**：固有模型差异分量小意味着代理与目标只需"预测对齐"，不需要架构、数据相似——降低代理模型选择的门槛。

**结果**：ResNet50 源 → 13 目标平均 ~98% ASR；ViT 93.52%、Swin 90.98%（首个 Transformer 上均值 90%+ 的迁移攻击）；最强防御组合上 72.81% vs 基线 56.35%。真实世界评估覆盖 Google Cloud Vision、四大搜索引擎、GPT-4/Claude3。

**局限**：假设依赖 ReLU 二阶导为零（GELU/SiLU 需重审）；实验未直接与 PGN 对比；无统计显著性报告。

## 三、ANDA：从"优化单点"到"学习分布"（平坦性路线的旁支）

**定位**：不直接优化平坦性标量，而是把对抗攻击从 MAP 估计（找最优点）升级为贝叶斯推断（估计完整后验），是"点 → 分布"的范式转变。

**核心机制**：

1. 在每步迭代注入随机数据增强 → SGA 轨迹满足渐近正态性前提（恒定小学习率 α=ε/T 恰好满足）。
2. 存储轨迹前两阶矩：Polyak-Ruppert 平均估计均值 $\bar\delta$，偏差矩阵估计协方差 $\sigma = DD^T/(nT-1)$。
3. 从 $\mathcal{N}(\bar\delta, \sigma)$ 无限采样对抗样本；采样样本成功率与单次生成相当——证明分布确实捕获了局部最优周围的几何结构，而非记忆单次结果。
4. **MultiANDA**：K 次随机初始化 → K 个高斯分量 → 深度集成近似高斯混合，覆盖多个吸引盆。

**统一目标**：$\max_{\Pi_\delta}\mathbb{E}_{\delta\sim\Pi_\delta}\sum_i \mathcal{L}(\texttt{AUG}_i(x+\delta), y)$——当 $\Pi_\delta$ 退化为 Dirac 分布时就是标准 BIM。

**与平坦性主线的交集**：近似的后验"本质描述了 SGA 迭代的稳态分布，捕捉局部最优周围的几何信息"——即**用分布宽度而非曲率表征邻域平坦度**。这是理解"平坦性"的另一种几何语言。

**结果与局限**：IncRes-v2 源黑盒均值 87.7%（VMI-FGSM +15%）；同时欺骗 6 模型 863/1000。但只与 2018-2021 基线对比，在 [[2026_MEF]] 的基准中被平坦性方法超越——说明**仅靠分布估计不如结合平坦性优化**；协方差存储开销大；VGG-19 源性能塌陷。

## 四、GAA：显式平坦性度量 + 三损失聚合

**定位**：把"平坦性"从隐式副产物变成**显式可度量、可优化**的量，并给出理论上优雅的平坦性代理指标。

**三个条件**：理想对抗样本应满足 ① 自身损失低（经验损失）；② 邻域内损失均匀低（最坏感知损失 $L_w = \max_{\|\tau\|\le\rho} L(x'+\tau)$）；③ 平坦性可度量（替代间隙损失）。

**核心理论——替代间隙**：二阶泰勒展开后：

$$h(x') = L_w - L \approx \frac{1}{2}\rho^2 \sigma_{\max}(H) \ge 0$$

**替代间隙正比于 Hessian 最大特征值**——最小化 h 等价于显式压平损失景观。一阶展开还给出 $h \approx \rho\|\nabla L\|_1$，从而把 RAP 的"最坏损失"与 PGN 的"梯度范数"统一进同一个量，构成从零阶到二阶的桥。

**最坏方向解析解**（Hölder 对偶）：

$$\hat\tau \approx \rho \cdot \frac{\nabla L(x')}{\|\nabla L(x')\|_1}$$

只需一次额外前向传播。最终梯度聚合：

$$g' = \hat g + (1-\lambda)g' + (1+\lambda)\hat g \;\Longleftrightarrow\; \min (1{-}\lambda)L(x') + (1{+}\lambda)L(x'{+}\hat\tau)$$

目标函数中**同时显式含一阶项与 Hessian 二次项**——作者直接引用 [[2024_TPA]] 的理论支撑这一设计。

**结果**：Inc-v3 源 → Inc-v4 92.0%（比 PGN +7.5%）；对抗训练模型平均比 MI +42.1%；六种异架构 71.1%（IncRes-v2 源）；与 DIM/TIM/SIM/Admix/SSA 全部正交可叠加；Wilcoxon 检验全部显著。

**局限**：平坦性→迁移性仍是经验连接；泰勒近似误差未量化；λ/ξ/N 需逐场景调优。

## 五、MEF：统一分类、理论收口与极大极小期望平坦性

**定位**：目前这条线的 SOTA 收口。做了三件事——统一碎片化的平坦性定义、建立第一个严格理论（Theorem 1）、解决探索-利用困境。

### 统一分类框架

定义 n 阶最坏/平均平坦性：

$$\hat R_\xi^{(n)}(x) = \max_{x'\in B_\xi(x)}\|\nabla^n J(x') - \nabla^n J(x)\|_2,\qquad R_\xi^{(n)}(x) = \mathbb{E}_{x'\sim\mathrm{Unif}(B_\xi(x))}[\|\nabla^n J(x') - \nabla^n J(x)\|_2]$$

| 方法 | 平坦性类型 | 阶数 |
|---|---|---|
| RAP | 最坏情况 | 0 阶 |
| GNP、PGN | 最坏情况 | 1 阶 |
| FEM、APP | 平均情况 | 0 阶 |
| TPA | 平均情况 | 1 阶 |

### 探索-利用困境

最坏情况法对局部极值高度敏感，在敏感峰间振荡 → 迭代间梯度相似性仅 0.10-0.25（**过探索**）；平均情况法被局部主导梯度拖入次优平台 → 相似性 0.38-0.88（**过利用**）。两种缺陷都导致优化过早停滞。

### Theorem 1：平坦性-可迁移性上界

定义对抗可迁移性间隙 $ATG = J(x+\delta; F') - J(x+\delta; F)$，多阶泰勒展开逐阶定界：

$$|ATG| \le \sum_{n=0}^{N}\frac{\|\delta\|^n}{n!}\left[\bar R_\xi^{(n)}(x;F) + C_n(x) + \bar R_\xi^{(n)}(x;F')\right] + \Delta R_N$$

三个贡献：**源模型平坦性（攻击者唯一可控）+ 跨模型梯度差异 $C_n$ + 目标模型平坦性**。系数 $\|\delta\|^n/n!$ 使高阶指数衰减，ReLU 网络下**零阶平均平坦性主导**——为"优化什么"给出理论依据，同时补上 TPA 只分析到 n=1 的局限。

### MEF 方法

极大极小双层结构：外层在 $B_\gamma$（γ=2ε）采样保持**探索** + 内层在 $B_\xi$（ξ=0.15ε）平均保证**利用**；NCS 用符号梯度更新把随机采样点推入最坏区域；**GBO 用上一轮外梯度复用替代内最小化**，计算量减半。

**结果**：MEFH（T=10）以 PGN 一半预算（200 BP vs 400 BP）超其 4.3%；MEFF（T=20，同预算）超 8.5%；PGN 等在 T=10 后过拟合停滞，MEF 持续增益至 T=36（峰值 96.40%）——**平坦性优化的真正红利在于延后过拟合**。防御模型 +8.46%，MeanSparse 21.1% vs 11.6% 近乎翻倍；Google Cloud Vision 79.4%（超 PGN 12.2%）；Qwen2.5-VL 41.5%（超 FEM 14%+）。

**局限**：ATG 假设源/目标在干净样本上损失对齐（跨架构/商业 API 时被违反但经验上仍有效）；μ_inner 敏感（贡献 ~10%）；"零阶主导"依赖 ReLU 假设。

## 六、共性技术底座

1. **Hessian 免算技巧**（五篇都在解决同一件事）：有限差分梯度插值（PGN）、梯度差分 Hv 近似（TPA）、Hölder 最坏方向解析解（GAA）、外梯度复用（MEF-GBO）。
2. **邻域采样 + 平均降方差**：N=20 几乎成为标准配置；采样半径 ζ≈3-3.5ε；平衡系数 λ/δ≈0.2/0.5。
3. **损失面可视化作为"平坦性证据"**：PGN 等高线图、GAA loss contour + Grad-CAM、MEF 蒙特卡洛估计 $R_\xi^{(0)}$ 定量验证——都靠它闭环论证。
4. **与输入变换正交**：五篇均验证与 DIM/TIM/SIM/Admix/SSA 可叠加——平坦性优化是梯度层机制，数据增强是输入层机制，互不冲突。

## 七、理论结论的层层修正

| 阶段 | 论断 | 修正者 |
|---|---|---|
| 2023 | 平坦 → 迁移（纯假设，实证支持） | PGN |
| 2024 | 平坦性只是三因素之一；二阶曲率同样决定迁移；单纯平坦可能次优 | TPA |
| 2025 | 平坦性需要显式二阶度量（σ_max），且要同时保白盒有效 | GAA |
| 2026 | n 阶统一框架；零阶主导；最坏/平均是互补而非对立，需极大极小平衡 | MEF |

贯穿始终的未决问题：**这些结论都是方法级（method-level）的全局标量论证**——没有任何工作检验过：在控制源损失、margin、扰动预算之后，某个**逐图（per-image）的平坦性统计量**能否预测 held-out 目标模型上的迁移失败。TPA 已证明"平坦性不充分"，MEF 已证明"要分阶分类"，但"哪个方向、哪种尾部统计量对单张图有预测力"仍是一个空白。

## 八、与当前研究（CD-DGAA / 条件方向平坦性）的衔接

把 CD-DGAA 放进 MEF 的四象限分类：

- 它测量沿**当前冻结动量方向 d** 的偶/奇损失变化 $q(z,d) = \tfrac12[J(z+\rho d)+J(z-\rho d)] - J(z)$，采样点 z 来自攻击自身的邻域分布；
- 在分类学上属于"**方向条件化的零/二阶混合、最坏情况（上尾）平坦性**"——MEF 的 $B_\xi$ 是各向同性球，CD-DGAA 的邻域是**以方向 d 为中心的条件分布**，这是四象限之外的一个新维度；
- 用上尾统计量（q90/CVaR）而非均值，与 PGN 选 max 不选 avg 的动机一脉相承，但把"平坦性"从优化目标变成了**可逐图验证的预测问题**（C01）。

这条综述线的共同盲区，恰好是当前 `ara/` 研究计划的切入点：方法级平坦性优化（PGN→MEF）与逐图条件平坦性预测（CD-DGAA audit）是互补而非竞争的两条腿。
